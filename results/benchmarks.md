DDoS and botnet C2 flows have ordinary values feature by feature, so the Isolation Forest's axis-aligned splits miss them; no benign flow has the same combination of values, which the nearest-neighbour distance captures. Botnet detection relies partly on its unusual service port (8080), which is specific to this testbed.
